写实小兔子桌宠 1.0.0（Windows x64 便携版）

使用方法
1. 将压缩包完整解压到任意文件夹。
2. 双击 RabbitDesktopPet-1.0.0-portable.exe。
3. 程序启动后，小兔子会出现在桌面底部；隐藏、退出和开机启动等功能位于任务栏右下角托盘菜单。
4. 退出时，请右键托盘里的小兔子图标并选择“退出桌宠”。
5. 托盘中分别提供“显示小兔子”和“隐藏小兔子”；按 Ctrl + Alt + R 或双击托盘图标也能快速切换显示状态。
6. 托盘中的“允许鼠标与小兔子互动”可以控制左右键是否生效。取消勾选后，鼠标会完全穿透桌宠；重新勾选即可恢复。

互动方式
- 左键短按兔子：互动。
- 左键长按兔子：从侧面伸出小手，跟随鼠标揉兔子。
- 右键短按兔子：打开喂食、睡觉、戴上/摘下草帽等菜单。
- 右键长按兔子：显示捏握手，拎起并移动兔子。
- 左键长按胡萝卜：移动胡萝卜；兔子会追过去吃掉它。

运行条件
- Windows 10/11 64 位。
- 无需安装 Deepseek Harness、Node.js、Blender 或 Electron。
- 建议开启显卡硬件加速；较老设备也可以运行，但动画帧率可能较低。

常见提示
- 这是未购买代码签名证书的个人开源程序。Windows SmartScreen 首次可能提示“Windows 已保护你的电脑”；确认文件来自可信发送者后，可选择“更多信息”→“仍要运行”。
- 程序是便携版，不写入安装目录。开机启动仅在托盘菜单中主动勾选后启用。
- 如果桌宠没有显示，按 Ctrl + Alt + R、双击托盘图标，或在托盘菜单选择“显示小兔子”。
